Tadaa! 🎉

راهنمای راه‌اندازی — از انتشار سایت تا همگام‌سازی بین همه دستگاه‌ها، فقط با گیت‌هاب و یک «رمز سینک».

۰

انتشار سایت (یک بار)

  1. مخزن را روی گیت‌هاب پوش کنید.
  2. در Settings → Pages، بخش Source را روی GitHub Actions بگذارید.
  3. سایت شما: https://pouriasafari117.github.io/Online_todolist/

💡 تسک‌ها روی شاخه جدا (todolist-data) ذخیره می‌شوند؛ پس سینک‌کردن هیچ‌وقت سایت را دوباره نمی‌سازد.

۱

ساخت توکن (یک بار، ۲ دقیقه)

  1. بروید به صفحه ساخت توکن گیت‌هاب و Generate new token را بزنید.
  2. Repository access: فقط همین مخزن (Online_todolist).
  3. Permissions → Contents: مقدار Read and write.
  4. توکن (github_pat_…) را کپی کنید؛ دیگر نشان داده نمی‌شود.
۲

اتصال دستگاه اصلی

  1. سایت را باز کنید، دکمه ابری بالا (حالت نمایش) را بزنید.
  2. تب «من صاحب لیستم»: توکن را بچسبانید و یک رمز سینک (حداقل ۱۰ کاراکتر، چند کلمه تصادفی) انتخاب کنید.
  3. گزینه‌های «رمزنگاری داده‌ها» و «انتشار قفل رمزدار» روشن باشند.
  4. اتصال و ساخت رمز سینک — تمام! نشانگر باید «همگام شد» شود.

🔐 توکن داخل یک قفل AES-256-GCM می‌رود که کلیدش از رمز سینک شما ساخته می‌شود؛ فایل قفل روی سایت عمومی است ولی بدون رمز فقط نویز است.

۳

وصل کردن دستگاه‌های دیگر (بدون توکن!)

  1. همان لینک سایت را روی دستگاه جدید باز کنید.
  2. دکمه ابری → تب «با رمز سینک وارد می‌شم».
  3. وقتی بنر «قفل سینک پیدا شد» آمد، رمز سینک را بزنید و وارد شوید.
  4. روی دستگاه شخصی، «این دستگاه رو به خاطر بسپار» را روشن بگذارید.

از این به بعد هر تغییری روی همه دستگاه‌ها دیده می‌شود. شناسه سینک (مثل TADA-1F2A-9C4D) را در تنظیمات هر دو دستگاه مقایسه کنید.

سناریوهای مهم

سناریوراه‌حل
تغییر رمز سینکتنظیمات → همگام‌سازی → تغییر رمز سینک؛ دستگاه‌های دیگر رمز جدید را می‌زنند.
گم شدن گوشیتوکن را در گیت‌هاب Revoke کنید، توکن تازه بسازید، دوباره وصل شوید و رمز را عوض کنید.
توکن منقضی شدتوکن جدید بسازید و روی دستگاه اصلی دوباره وصل شوید (رمز سینک می‌تواند همان بماند).
رمز را فراموش کردمبازیابی ندارد — با توکن جدید از قدم ۲ دوباره شروع کنید و رمز را در پسوردمنیجر نگه دارید.
