# معماری Tadaa!

یک وب‌اپ **کاملاً استاتیک و بدون بک‌اند**: سه فایل CSS و دو فایل JS (بدون هیچ وابستگی و بدون مرحله Build) که روی GitHub Pages میزبانی می‌شود و از GitHub REST API به‌عنوان دیتابیس استفاده می‌کند.

```
┌─────────────── مرورگر (هر دستگاه) ───────────────┐
│  index.html + assets/css + assets/js (Vanilla)   │
│  state → render → localStorage (حالت آفلاین/دمو)  │
└───────┬───────────────────────────┬──────────────┘
        │ GET todolist/vault.json   │ Contents API (با توکن)
        ▼ (از خود سایت Pages)        ▼
┌────────────────┐        ┌──────────────────────────────┐
│ قفل رمزنگاری‌شده │        │ شاخه todolist-data            │
│ روی شاخه main   │        │ └─ data/todos.json            │
└────────────────┘        └──────────────────────────────┘
```

## چرا دو شاخه؟

| شاخه | محتوا | چه کسی می‌نویسد |
|---|---|---|
| `main` | کد سایت + `todolist/vault.json` | شما (توسعه) و اپ هنگام انتشار/چرخش قفل |
| `todolist-data` | فقط `data/todos.json` | اپ، در هر سینک |

اگر داده روی `main` ذخیره می‌شد، هر تیکِ یک تسک یک کامیت و (با دپلوی خودکار) یک بازسازی سایت راه می‌انداخت. جدا کردن شاخه داده یعنی سینک تسک‌ها **هیچ ربطی به دپلوی ندارند** و تاریخچه `main` تمیز می‌ماند.

## فرمت داده (`data/todos.json`)

در حالت رمزنگاری‌شده (پیش‌فرض):

```json
{
  "format": "tadaa-data", "version": 2, "encrypted": true,
  "crypto": { "v": 1, "kdf": "PBKDF2-SHA256", "iter": 210000, "salt": "…", "iv": "…", "data": "…" }
}
```

متن رمزگشایی‌شده:

```json
{
  "version": 2, "app": "tadaa", "updatedAt": "2026-…",
  "tasks": [{ "id": "…", "title": "…", "notes": "", "priority": "high|normal|low",
              "due": "YYYY-MM-DD", "tags": ["…"], "done": false,
              "createdAt": "…", "updatedAt": "…", "completedAt": null, "order": 1 }],
  "tombstones": { "<taskId>": "<زمان حذف ISO>" }
}
```

اگر رمزنگاری داده خاموش شود، همان ساختار با `"encrypted": false` و فیلد `data` به‌صورت خوانا ذخیره می‌شود (قفل Vault در هر صورت رمزنگاری است).

## چرخه سینک

1. **تغییر محلی** → `state.dirty = true` → ذخیره محلی فوری → Push با Debounce حدود ۱.۲ ثانیه.
2. **Push** با GitHub Contents API (`PUT` با `sha` فعلی). پاسخ `409/422` یعنی دستگاه دیگری جلو زده: اول Pull + Merge، بعد Retry (یک بار).
3. **Pull** هنگام باز شدن اپ، برگشتن به تب (`visibilitychange`)، آنلاین شدن و هر ۴۵ ثانیه.
4. **Merge:** اتحاد بر اساس `id`؛ برای هر تسک نسخه‌ای که `updatedAt` بزرگ‌تری دارد می‌برد. حذف‌ها با `tombstones` منتقل می‌شوند و اگر زمان حذف از آخرین ویرایش تسک بزرگ‌تر باشد، تسک برنمی‌گردد.

## قفل سینک (Vault)

فایل `todolist/vault.json` روی سایت منتشر می‌شود:

```json
{ "format": "tadaa-vault", "version": 1, "vaultId": "…",
  "crypto": { "kdf": "PBKDF2-SHA256", "iter": 210000, "salt": "…", "iv": "…", "data": "…" } }
```

Payload رمزگشایی‌شده شامل `repo`، `branch`، `path`، `token`، `encryptData` و `vaultId` است. «شناسه سینک» (Fingerprint) که در اپ می‌بینید `SHA-256("tadaa:" + vaultId)` کوتاه‌شده است تا دو دستگاه بتوانند مطمئن شوند به یک لیست وصل‌اند.

«به خاطر سپردن دستگاه» یک لایه جدا و کاملاً محلی است: یک کلید تصادفی در `localStorage` همان مرورگر ساخته می‌شود و کانفیگ بازشده با آن (AES-GCM) قفل می‌شود؛ این کلید هرگز دستگاه را ترک نمی‌کند. جزئیات و مدل تهدید در [SECURITY.md](SECURITY.md).

## فرانت‌اند

- **بدون فریم‌ورک و بدون Build:** ماژول‌های ES بومی (`lib.js` برای کریپتو/API و `app.js` برای UI).
- **تم روز/شب:** متغیرهای CSS + `theme-init.js` که قبل از اولین Paint اجرا می‌شود تا فلش نوری نباشد؛ انتخاب Auto از `prefers-color-scheme` پیروی می‌کند.
- **دوزبانه (فا/انگلیسی):** دیکشنری در `lib.js`، با تغییر جهت `rtl/ltr` و فونت وزیرمتن/ Fredoka که **داخل مخزن** میزبانی می‌شوند (بدون CDN).
- **PWA:** مانیفست + Service Worker با استراتژی Cache-first برای شل آفلاین؛ ترافیک `api.github.com` و فایل Vault هرگز کش نمی‌شوند.
- **دسترس‌پذیری:** فوکوس‌های مرئی، `prefers-reduced-motion`، حالت کاهش انیمیشن داخلی، میان‌برهای کیبورد (`N`، `/`، `T`، `G`، `?`).

## محدودیت‌های آگاهانه

- GitHub Contents API برای فایل‌های کوچک عالی است؛ این دیتا حتی با هزاران تسک از چند صد کیلوبایت بزرگ‌تر نمی‌شود.
- نرخ مجاز API (۵۰۰۰ درخواست/ساعت برای هر توکن) با Debounce و Merge عملاً هیچ‌وقت لمس نمی‌شود.
- سینک «بلادرنگ» نیست؛ تأخیر معمول چند ثانیه است (Pull دوره‌ای + هنگام فوکوس).
