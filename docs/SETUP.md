# راهنمای راه‌اندازی Tadaa! — از صفر تا همگام‌سازی بین دستگاه‌ها

این راهنما قدم‌به‌قدم توضیح می‌دهد چطور لیست را روی GitHub Pages منتشر کنید، توکن بسازید، رمز سینک تعریف کنید و دستگاه‌های دیگر را فقط با همان رمز به لیست وصل کنید.

> **مدل ذهنی در یک جمله:** هیچ سروری وجود ندارد؛ مرورگر شما مستقیم با API گیت‌هاب حرف می‌زند، داده‌ها داخل مخزن خودتان ذخیره می‌شوند و «رمز سینک» کلیدی است که قفل رمزنگاری‌شده‌ی حاوی توکن را باز می‌کند.

---

## قدم ۰ — انتشار سایت (یک بار، توسط صاحب مخزن)

1. این مخزن را به گیت‌هاب پوش کنید (شاخه `main`).
2. در گیت‌هاب بروید به **Settings → Pages**.
3. در بخش **Build and deployment → Source** گزینه **GitHub Actions** را انتخاب کنید.
4. از تب **Actions** مطمئن شوید ورک‌فلوی `Deploy Tadaa! to GitHub Pages` سبز شده است.
5. آدرس سایت شما می‌شود:
   `https://pouriasafari117.github.io/Online_todolist/`

> اگر مخزن Private است، GitHub Pages به پلن پولی نیاز دارد؛ مخزن را Public کنید — اشکالی ندارد، چون (قدم ۳) داده‌ها رمزنگاری می‌شوند و متن کارها در مخزن عمومی هم خوانا نیست.

از این به بعد، هر پوش روی `main` که فایل‌های سایت را تغییر دهد، سایت را خودکار به‌روز می‌کند. **نکته مهم:** تغییرات تسک‌ها روی شاخه جدا (`todolist-data`) ذخیره می‌شوند، پس سینک‌کردن تسک‌ها هیچ‌وقت باعث بازسازی/ری‌دپلویمنت سایت نمی‌شود.

## قدم ۱ — ساخت توکن گیت‌هاب (یک بار، حدود ۲ دقیقه)

توکن مثل کلید گاوصندوق است؛ فقط **یک بار** و فقط روی **یک دستگاه** ساخته می‌شود:

1. بروید به <https://github.com/settings/tokens?type=beta>
2. **Generate new token** را بزنید.
3. **Token name:** مثلاً `tadaa-todolist`
4. **Expiration:** به دلخواه (پیشنهاد: ۱ سال؛ وقتی منقضی شد از داخل اپ، دستگاه اصلی دوباره وصل می‌شود و قفل جدید منتشر می‌کند).
5. **Repository access:** گزینه **Only select repositories** و همین مخزن (`Online_todolist`) را انتخاب کنید.
6. **Permissions → Repository permissions → Contents:** مقدار **Read and write**.
7. **Generate token** و توکن (`github_pat_…`) را کپی کنید. این صفحه دیگر نشان داده نمی‌شود!

## قدم ۲ — اتصال دستگاه اصلی (Owner)

1. سایت را باز کنید و روی دکمه ابریِ بالای صفحه (**حالت نمایش**) بزنید.
2. تب **«من صاحب لیستم»**:
   - **مخزن گیت‌هاب:** `pouriasafari117/Online_todolist` (پیش‌فرض پر شده است)
   - **اسم این دستگاه:** مثلاً «لپ‌تاپ من»
   - **توکن:** همان `github_pat_…`
   - **رمز سینک:** یک رمز حداقل ۱۰ کاراکتری که **یادتان بماند**؛ بهترین انتخاب چند کلمه تصادفی است، مثل `piano-purple-river-42`. این رمز از این به بعد «کلید ورود همه دستگاه‌ها»ست.
   - **داده‌ها رمزنگاری بشن:** روشن بماند (پیشنهاد جدی).
   - **انتشار قفل رمزدار روی سایت:** روشن بماند تا دستگاه‌های دیگر فقط با رمز وصل شوند.
3. **اتصال و ساخت رمز سینک** را بزنید.

پشت صحنه چه می‌شود؟
- یک شاخه به نام `todolist-data` ساخته می‌شود و فایل `data/todos.json` روی آن قرار می‌گیرد.
- یک «قفل» (Vault) ساخته می‌شود: توکن + آدرس مخزن با رمز سینک شما و الگوریتم AES-256-GCM رمزنگاری می‌شود و فایل `todolist/vault.json` روی سایت منتشر می‌شود. این فایل برای هر کسی که رمز را ندارد فقط یک مشت بایت تصادفی است.

از حالا دکمه ابری باید **«همگام شد»** را نشان دهد. هر تغییری (افزودن، تیک‌زدن، ویرایش، حذف، جابه‌جایی) حدود یک ثانیه بعد خودکار روی گیت‌هاب ذخیره می‌شود.

## قدم ۳ — وصل کردن دستگاه‌های دیگر (بدون توکن!)

روی هر دستگاه جدید (موبایل، تبلت، کامپیوتر دیگر):

1. همان آدرس سایت را باز کنید.
2. دکمه ابری → تب **«با رمز سینک وارد می‌شم»**.
3. صبر کنید بنر **«قفل سینک پیدا شد»** سبز شود.
4. **رمز سینک** را وارد کنید و **باز کردن قفل و همگام‌سازی** را بزنید.
5. گزینه **«این دستگاه رو به خاطر بسپار»** را اگر دستگاه شخصی شماست روشن بگذارید تا دفعات بعد بدون رمز باز شود.

تمام! دیگر هیچ‌وقت روی این دستگاه توکن لازم نیست. تغییرات روی همه دستگاه‌ها (با چند ثانیه تأخیر یا با دکمه همگام‌سازی) دیده می‌شوند.

**جایگزین (وقتی قفل روی سایت منتشر نشده):** صاحب لیست از **تنظیمات → همگام‌سازی → دعوت دستگاه دیگه → کپی کد پشتیبان** یک کد رمزنگاری‌شده (`TD1.…`) می‌گیرد و برای شما می‌فرستد؛ در همان تب، بخش «کد دعوت دارم» را باز کنید، کد را بچسبانید و بعد رمز سینک را بزنید.

از صاحب لیست، **شناسه سینک** (مثل `TADA-1F2A-9C4D`) را هم بگیرید و در **تنظیمات → همگام‌سازی** هر دو دستگاه مقایسه کنید؛ باید دقیقاً یکی باشند.

## قدم ۴ — کارهای روزمره و سناریوها

| سناریو | چه کار کنم؟ |
|---|---|
| رمز سینک را عوض کنم | دستگاه اصلی: **تنظیمات → همگام‌سازی → تغییر رمز سینک**. قفل جدید منتشر می‌شود و داده‌ها با رمز جدید دوباره رمزنگاری می‌شوند؛ دستگاه‌های دیگر باید رمز جدید را یک بار وارد کنند. |
| توکن منقضی/باطل شد | در گیت‌هاب توکن جدید بسازید (قدم ۱) و روی دستگاه اصلی از نو وصل شوید (**حالت نمایش → من صاحب لیستم**). رمز سینک می‌تواند همان قبلی بماند تا دستگاه‌های دیگر اذیت نشوند. |
| گوشی‌ام گم شد | از دستگاه اصلی **رمز سینک را عوض کنید** (دستگاه گمشده دیگر قفل جدید را باز نمی‌کند) و توکن را در گیت‌هاب **Revoke** کنید. |
| یک دستگاه را جدا کنم | روی همان دستگاه: **تنظیمات → همگام‌سازی → قطع اتصال این دستگاه**. داده‌ها روی گیت‌هاب می‌مانند. |
| آفلاین کار کنم | مشکلی نیست؛ تغییرات محلی ذخیره می‌شوند و وقتی آنلاین شوید خودکار سینک می‌شوند. نشانگر ابری وضعیت را نشان می‌دهد. |
| دو دستگاه همزمان ویرایش کردند | ادغام خودکار بر اساس زمان ویرایش هر تسک انجام می‌شود؛ حذف‌ها هم با «سنگ‌قبر» (Tombstone) همگام می‌شوند تا تسک حذف‌شده زنده نشود. |

## رفع اشکال (FAQ)

- **بنر می‌گوید «قفل روی سایت نیست»:** یا صاحب لیست گزینه انتشار قفل را خاموش کرده (از کد دعوت استفاده کنید)، یا دپلوی GitHub Pages هنوز تمام نشده؛ یک دقیقه صبر کنید و صفحه را رفرش کنید. مطمئن شوید آدرس را روی همان مخزنی باز کرده‌اید که قفل در آن منتشر شده.
- **«توکن قبول نشد»:** توکن باید Fine-grained باشد، فقط همین مخزن را شامل شود و دسترسی **Contents: Read and write** داشته باشد. توکن‌های کلاسیک (`ghp_…`) هم کار می‌کنند ولی دسترسی‌شان گسترده‌تر است و توصیه نمی‌شوند.
- **«رمز اشتباهه»:** رمز سینک به حروف کوچک/بزرگ و فاصله حساس است؛ دوباره با دقت وارد کنید. راه بازیابی وجود ندارد (عمداً!) — در این صورت صاحب لیست باید از قدم ۲ دوباره وصل شود.
- **تغییرات دستگاه دیگر را نمی‌بینم:** دکمه ابری را بزنید (**همگام‌سازی الان**) یا صفحه را رفرش کنید. اپ هر ۴۵ ثانیه و هنگام برگشتن به تب، خودکار چک می‌کند.
- **سایت آپدیت نمی‌شود:** تب Actions را بررسی کنید. یادتان باشد دیتای تسک‌ها روی شاخه `todolist-data` است و عمداً باعث دپلوی نمی‌شود؛ فقط تغییرات ظاهری سایت دپلوی می‌خواهد.
- **روی آیفون/اندروید نصب کنم:** در مرورگر، Share → **Add to Home Screen**؛ اپ به صورت PWA نصب می‌شود و آفلاین هم باز می‌شود.
