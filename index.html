همگام‌سازی با گیت‌هاب

یه توکن گیت‌هاب بساز، اینجا بذار، و یه رمز سینک انتخاب کن. از این به بعد همه دستگاه‌ها با همون رمز به لیستت می‌رسن.

توکن فقط برای همین یک مخزن

با این لینک، گیت‌هاب خودش اسم، انقضا و دسترسی Contents رو پُر می‌کنه؛ تو فقط دو انتخاب داری:

  1. در Repository access گزینه «Only select repositories» را انتخاب کن.
  2. فقط همین مخزن را انتخاب کن: —
  3. در Repository permissions فقط Contents را روی «Read and write» بگذار.
ساخت توکن در گیت‌هاب (پُرشده)

توکن کلاسیک (ghp_…) قبول نمی‌شود چون به همهٔ مخزن‌های تو دسترسی می‌دهد.

تنظیمات پیشرفته

فایل داده در یه شاخه جدا ذخیره می‌شه تا ساخت خودکار سایت گیت‌هاب رو به هم نریزه.

ساخت توکن درست برای همین مخزن

توکن فقط برای درخواست‌های API به گیت‌هاب فرستاده می‌شه و داخل قفل رمزنگاری‌شده نگه داشته می‌شه. با روشن‌کردن «به خاطر بسپار»، یک نسخه‌ی رمزنگاری‌شده هم روی همین مرورگر می‌مونه.

کد دعوت یا لینک اختصاصی دارم

اگه قفل روی سایت منتشر نشده، کد رمزنگاری‌شده‌ای که صاحب لیست بهت داده رو اینجا بذار.

رمز سینک رو از صاحب لیست بگیر. رمز اشتباه = قفل باز نمی‌شه و هیچ داده‌ای لو نمی‌ره.
